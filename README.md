# 电科-简单MUD游戏

## 亮点

1. 协作项目
2. 使用C/C++构建
3. 纯自行编写`CMakeLists.txt`规则

## 构建

```shell
cd cmake-build-debug
cmake ../
make
./Bin/V4_DK_SMPGM
```
